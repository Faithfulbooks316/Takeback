## Termux Field Guide

Open [termux-cheatsheet.html](termux-cheatsheet.html) in a browser or HTML viewer for a searchable, offline-friendly Termux package and command reference.

## Deployment

The site is static and can be deployed from the repository root. Netlify uses the included `netlify.toml`; GitHub Pages deploys automatically on pushes to `main` after Pages is configured to use **GitHub Actions** in the repository settings.
